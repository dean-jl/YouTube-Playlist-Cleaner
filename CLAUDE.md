## 🎯 Project Overview

The **YouTube Playlist Cleaner** is a Manifest V3 browser extension for Google Chrome and Microsoft Edge that allows users to selectively filter, preview, and batch delete videos from their YouTube playlists.

### Core User Journey

1. **Navigate**: User navigates to a YouTube playlist page (`youtube.com/playlist?list=...`).
2. **Configure**: User opens the extension popup, sets deletion filters (title keywords, channel names, age in days/weeks/months/years, watched status/percentage, unavailable/private videos), and chooses match logic (AND / OR) or Dry Run mode.
3. **Scan & Load**: Extension auto-scrolls to load all playlist items into the DOM.
4. **Delete**: Extension evaluates videos against filters, clicks YouTube's native remove actions, and provides an on-screen progress/cancel badge.
5. **Report**: On completion, the extension automatically downloads a summary `.txt` report of all matched/processed videos.

## 🛠️ Development, Testing & Packaging

```bash
# Build the TypeScript code and assets into dist/
npm run build

# Run unit tests
npm test

# Package distribution zips for Chrome, Edge, Firefox, Safari into package/
npm run package

# Target specific browsers
npm run package:chrome
npm run package:edge
npm run package:firefox
npm run package:safari

# Audit and verify packages
npm run verify:package

# Load into Browser
1. Navigate to chrome://extensions or edge://extensions
2. Enable "Developer mode"
3. Click "Load unpacked" and select the dist/ folder (or root project after build)
4. Reload the extension after re-building
```

## 🏛️ Architecture & Components

- `src/manifest.json` — Manifest V3 declaration (permissions: `activeTab`, `webNavigation`, `scripting`, host permission: `https://www.youtube.com/*`).
- `src/background.ts` — Service worker listening to `webNavigation.onHistoryStateUpdated` for SPA playlist navigation and ensuring `content.js` is available.
- `src/content.ts` — Injected content script handling auto-scrolling, video metadata extraction, filter matching, menu automation, and summary export.
- `src/popup.html` & `src/popup.ts` — Popup UI for user filter criteria, validation, dry-run toggles, AND/OR logic selection, and dispatching execution messages.
- `scripts/package.js` — Packaging engine generating browser-specific `.zip` distribution packages (Chrome Web Store, Microsoft Edge Add-ons, Mozilla Firefox AMO, Apple Safari) and running schema/asset integrity audits.
- `package/` — Storage for generated release zip packages and store listing assets.
- `tests/` — Automated test suite using Node.js test runner (`node --test 'tests/**/*.test.mjs'`).
- `dist/` — Compiled extension bundle generated by `npm run build`.
